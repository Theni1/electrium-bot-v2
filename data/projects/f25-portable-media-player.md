## Description

A portable media player that combines the ideas of CarPlay and an earbud into one device that can attach to any of Electrium's electric vehicles. It uses the Bluetooth capabilities of the ESP32 microcontroller family to act as a host and pair with headphones. Using the configurable GPIO matrix and firmware peripheral controllers, the team built a custom PCB and firmware for streaming audio from a MicroSD card and showing information on an LCD screen.

## Features

- Bluetooth host pairing with headphones (ESP32)
- Custom PCB
- MicroSD audio streaming
- LCD display for playback and system information
- ESP32 firmware using the GPIO matrix and peripheral controllers
