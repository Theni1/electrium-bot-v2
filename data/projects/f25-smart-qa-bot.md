## Description

A Discord bot that acts as an AI interface to the team's internal documentation hosted on Outline. It understands natural language questions, works out which documentation collection has the relevant information, and retrieves specific documents to answer the user in Discord.

## Features

- Outline integration: Direct access to collections and nested document hierarchies.
- AI routing: Analyzes each question to pick the most helpful documentation collection.
- Path parsing: Parses document names in "Parent - Sub - Doc" format to locate specific files.
- Knowledge retrieval: Opens and reads Outline documents to give contextual AI answers.
