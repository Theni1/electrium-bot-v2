## Description

The Custom Remote Control is an adaptable controller designed to work with all current and future Electrium Mobility projects. It has a custom PCB with Bluetooth, an OLED display, and haptic feedback, and its receiver supports CAN for VESC communication.

## Features

### Custom Circuit Board

The PCB was designed from the ground up in KiCad, going from schematic capture to PCB layout to component soldering.

### Firmware

The firmware runs on an ESP32-C6 and supports Bluetooth communication between the remote and the vehicle. The OLED display and haptic vibration give real-time feedback on battery health, current speed, and adjustable settings. Advanced features include power-saving modes, customizable controls, and CAN bus integration with the VESC.

### Prototyping and Testing

The team built prototypes, pushed firmware updates for fine-tuning, and did extensive debugging, hardware adjustments, and firmware testing across multiple devices and settings.

### User Interface

The team refined the OLED interface to show clear, easy-to-read information with intuitive navigation.

## Goals

The main goal was to improve the team's electrical and firmware abilities. For many members it was their first time using KiCad and learning circuit design, schematic capture, soldering, component selection, and footprint design. The team also learned CAN bus and Bluetooth interfacing, controlling a VESC, programming microcontrollers to respond to user input, and driving the OLED display.
