## Description

A conversion kit that turns standard bicycles into e-bikes by installing a central motor near the pedals (a mid-drive configuration), which gives better climbing ability and higher torque. The kit includes a battery, a speed control system, and a user display.

## Features

- Central motor near the pedals (mid-drive configuration)
- Higher climbing ability
- Higher torque
- Battery system
- Speed control system
- User display
