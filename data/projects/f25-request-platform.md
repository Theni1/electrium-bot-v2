## Description

A task management system built for student design teams. It has a web interface gated by Discord authentication and a Kanban-style board for real-time task tracking, with drag-and-drop, batch status updates, and a "claim" system so members can pick up tasks instantly.

## Features

- Discord authentication: Only authorized server members can access the platform.
- Kanban board: Drag-and-drop columns for task status.
- Task claiming: A "Claim" button assigns the task to the user and moves it to the assigned column.
- Smart forms: Validated "Assign To" dropdowns and due date checks that block past dates.
- UX details: "Undo delete" toasts, hover-to-reveal icon labels, and collapsible archive sections.
- Batch operations: Change status and priority for multiple task cards at once.
